## About the Project

The Python Learning Platform is an interactive web application for learning Python programming, built with Flask and PostgreSQL. The full application includes:

- User registration and login
- Interactive lessons on Python basics
- Live code execution in the browser
- Progress tracking for users
- Responsive design for all devices

# Python Learning Platform

An interactive web application for learning Python programming, built with Flask and PostgreSQL.

## Features

- **User Registration and Login System**: Create an account to track your learning progress
- **Interactive Learning Content**: Structured lessons on Python fundamentals
- **Live Code Execution**: Practice Python code directly in your browser
- **Progress Tracking**: Mark lessons as completed and track your learning journey
- **Responsive Design**: Works on desktop and mobile devices

## Topics Covered

- Python Syntax
- Data Types
- Loops
- Functions

## Technology Stack

- **Backend**: Flask (Python)
- **Database**: PostgreSQL
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Interactive Code**: CodeMirror
- **Authentication**: Flask-Login

## Installation and Setup

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/PythonLearningPlatform.git
   cd PythonLearningPlatform
   ```

2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

3. Set up environment variables:
   ```
   export FLASK_APP=app.py
   export FLASK_ENV=development
   export DATABASE_URL=postgresql://username:password@localhost/dbname
   ```

4. Run the application:
   ```
   flask run
   ```
